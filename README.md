# Divisions: Command and Control (`division_ai` v1.0.0)

Two-tier naval tactical Command & Control (C2) layer, Time / Space / Firepower / Convergence battlefield evaluation, campaign-layer Permanent Divisions, Faction Fleet Doctrines, Cultural Nomenclature, and Tactical Map Warroom visualization for Starsector `0.98a-RC8`.

Vanilla ship AI awareness is hard-capped at a `1500–2200u` threat bubble with zero cross-ship state sharing (`BattleGroupAI.followOrders()` is empty in the shipped game). **Divisions: Command and Control** adds a cooperative two-tier C2 hierarchy — **Battle Group Commander (Officer in Tactical Command / OTC)** and **Division Commanders** — that evaluates **Time, Space, Firepower, and Convergence** across the battlefield, orchestrates multi-division plays and fleet-wide formations, routes divisions and stragglers along wide out-of-contact arcs around enemy battle lines, and drives individual ships via cooperative `ShipwideAIFlags` without replacing vanilla ship AI modules.

## Quick Build & Headless Test Suite

```bash
# Compile src/divisionai/*.java -> mod/jars/DivisionAI.jar
bash build.sh

# Run full headless 2D tactical C2 simulation + UI/UX harness + bytecode security check
```

- **Test Artifacts Generated by `./test.sh`**:
  - `build/sim_replay.html` — Interactive HTML5 Canvas tactical replay viewer across all 23 simulated battle scenarios.
  - `build/ui_preview.html` — Visual layout and copy succinctness audit report across all 41 UI/UX and 1:1 Starsector dialog simulation checks.
  - `build/droplet_qa_sheet.png` — 8-panel visual QA sheet for the Smooth-Union SDF (`smin`) + Marching Squares water-droplet division polygons.

## Codebase Architecture & Module Map (`src/divisionai/`)

The 22 production classes in `src/divisionai/` are organized into four clean layers:

### 1. Core Data Model, Ship Capability & Battlefield Domain Analysis
- **`DivisionModel.java`**
  - Canonical enums and runtime state objects:
    - `DivisionArchetype` (16 archetypes: `BATTLESHIP_DIVISION`, `MISSILE_BATTLESHIP_DIVISION`, `CRUISER_DIVISION`, `MISSILE_CRUISER_DIVISION`, `STRIKE_CRUISER_DIVISION`, `DESTROYER_DIVISION`, `MISSILE_DESTROYER_DIVISION`, `FRIGATE_DIVISION`, `MISSILE_FRIGATE_DIVISION`, `FLEET_CARRIER_DIVISION`, `LIGHT_CARRIER_DIVISION`, `ESCORT_CARRIER_DIVISION`, `CARRIER_GROUP`, `PHASE_DIVISION`, `SERVICE_GROUP`, `FORCE_DIVISION`).
    - `MissionContextType`, `BattlePhase`, `DivisionIntentType`, `OtcOrderType`, `OtcOrder`, `StrikePlan`, `CommanderProfile`, `DivisionState`, and `BattleGroupState`.
- **`ShipCapabilityProfile.java`**
  - Analyzes a combat `ShipAPI` or campaign `FleetMemberAPI` (hull size, DP strength via `resolveShipFpStrength`, strike/torpedo mounts restricted to `AIHints.STRIKE`, non-PD gun ranges, PD weight, fighter bays, speed, and phase cloak).
- **`BattlefieldFirepowerEvaluator.java`**
  - Evaluates the three geometric domains across all ships and divisions:
    - **Time** (`freeTimeRadius`, `effectiveTimeRadius`, `directionalTimeRadii[24]`): 12s maneuver horizon deformed along pinned contact bearings.
    - **Space** (`spaceInnerRadius`, `spaceDominatedRadius`, `spacePotentialRadius`): weighted effective HP (hull, 15x15 armor grid, shield/flux capacity), friendly Strongpoints (`isStrongpoint`), and exposed Weak Points / Seams (`isWeakPoint`).
    - **Firepower**: 24-sector (`15°` per sector) Polar Firepower Rose across Alpha Strike (`0–2s`), Burst (`4–6s`), Sustained (`15–30s`), and Point Defense channels, plus multi-division L/U-shaped Crossfire Cordons.
    - **Convergence** (`computeConvergenceTargetScore`): Alpha Core non-linear multiplicative phase-space scoring across Time, Space, and Firepower simultaneously.

### 2. Battle-Layer Tactical C2 Engine
- **`DivisionAICombatPlugin.java`**
  - `BaseEveryFrameCombatPlugin` registered in `mod/data/config/settings.json`.
  - Manages independent `BattleGroupState` instances for Player (`side 0, !isAlly`), Allied AI (`side 0, isAlly`), and Enemy (`side 1`), plus the mid-battle OTC Control Strip and Formation Wheel (`86x86` icons).
- **`DivisionOtcCommandManager.java`**
  - Manages Officer in Tactical Command (OTC) flagship/commander selection (`Auto` or explicit officer/AI core), continuity on flagship destruction, urgent Alpha Core assumption-of-command hails, and active command style switching.
- **`DivisionAutoFormer.java`**
  - Forms combat `DivisionState` instances at battle start and absorbs trickle reinforcements (`findExistingDivisionForReinforcement` within `<= 2200u` of division centroid).
  - Computes true RMS line-abreast `stationKeepingRadius` (`computeStationKeepingRadius`).
- **`OtcAI.java`**
  - Officer in Tactical Command (1.5s cadence): updates Core-Cluster cohesion & decouples cut-off stragglers (`detachedStragglerIds`), evaluates Fog-of-War-filtered spatial-grid force ratios, designates `mainEffortDivision` and `reserveDivision`, and transitions `BattlePhase`.
- **`OtcBattlePlanner.java`**
  - Translates the OTC's battle phase, `FleetWideFormation`, `MultiDivisionSetpiece`, and enabled `OtcPlay`s (`LINE_AND_FIRE_DISTRIBUTION`, `DOUBLING`, `TIME_ON_TARGET_STRIKES`, `RESERVE_AND_GENERAL_CHASE`, `MARTYRDOM`) into per-division `OtcOrder`s gated by `OtcAuthority`.
- **`DivisionCommanderAI.java`**
  - **Section 1**: Main 0.5s evaluation loop (`evaluateAndExecuteDivisions`) & Mission / Martyrdom predicates.
  - **Section 2**: 13-step Division Intent priority ladder (`selectDivisionIntent`, `trySelectWithdrawalOrVentIntent`, `trySelectCarrierMissionIntent`, `trySelectCombatMissionIntent`, `selectFallbackTacticalIntent`).
  - **Section 3**: OTC order application (`applyOtcOrder`).
  - **Section 4**: Station point & formation slot geometry (`refreshStationPoint`, `computeShipFormationSlot`, `computeStandoffStation`, `computeScreeningStation`, `computeFlankStation`, `computePatrolStation`).
  - **Section 5**: Per-ship cooperative `ShipwideAIFlags` execution (`applyDivisionFlagsToShips`, `applyIntentFlagsToShip`, `hasExplicitCommandOrder`).
  - **Section 6**: Target & objective queries (`findBestEnemyDivisionFor`, `findEndangeredFriendlyDivision`, `findHeavyFriendlyDivisionToScreen`, `pickFocusEnemyShip`, `findTaskManagerObjectiveForDivision`, `findNearestContestObjective`).
  - **Section 7**: Battlespace awareness & out-of-contact wide-arc routing (`updateDivisionOutOfContactRoute`, `computeOutOfContactRoutePoint`).
- **`DivisionCombatLog.java`**
  - Unconditionally logs all C2 telemetry to `starsector.log` (`emitLogLine`), and filters on-screen HUD combat messages (`CombatUIAPI.addMessage`) according to `DivisionAISettings.ChatterVerbosity` (`Verbose`, `Standard`, `Minimal`, `OTC Only`, `Off`; default `Minimal`) and per-side/tier toggles.

### 3. Campaign Layer: Permanent Divisions, Faction Doctrines & Cultural Nomenclature
- **`DivisionAIModPlugin.java`**
  - Campaign lifecycle hooks (`onApplicationLoad`, `onNewGameAfterTimePass`, `onGameLoad`).
- **`PermanentDivisionManager.java`**
  - Persists player Permanent Divisions (`divisionai_permanent_divisions_v2`) and Fleet Doctrine (`divisionai_fleet_doctrine_v1`) in sector persistent data using XStream-safe JDK `List`/`Map` structures.
  - Enforces `MAX_DIVISION_SIZE = 10`, auto-calculates division standoff range from longest non-PD weapons/wings, classifies fleet members across the 16 archetypes (`classifyFleetMemberArchetype`), and bridges campaign divisions into combat (`applyPermanentDivisionsInCombat`, `applyDoctrineModifiersToCombatDivision`).
- **`FactionFleetDoctrines.java`**
  - Lore-accurate `FleetDoctrineConfig` definitions for all vanilla factions (`hegemony`, `tritachyon`, `persean`, `sindrian_diktat`, `lions_guard`, `luddic_church`, `knights_of_ludd`, `luddic_path`, `pirates`, `independent`, `mercenary`, `scavengers`, `remnant`, `derelict`, `threat`, `dweller`, `omega`).
  - Maintains persistent per-faction division record tables (`$divisionai_factionDivisionTables_v1`) with story-fleet priority preemption, sticky AI fleet divisions, and whole-division transfers between nearby same-faction fleets.
- **`DivisionNomenclature.java`**
  - Cultural division & OTC naming across all 8 player-selectable `PlayerNamingPreset`s (plus spoiler-protected NPC presets for Remnant, Threat, and Abyssal forces) and all 16 `DivisionArchetype`s, shared prefix bucket numbering (`resolvePrefixBucketKey`), SplitMix64 deterministic variation (`mixSeed64`), and lore-accurate Threat/Abyssal formatting.

### 4. UI & Tactical Map Warroom Visualization Layer
- **`DivisionTacticalMapOverlay.java`**
  - Warroom `CustomPanelAPI` attachment & top-level `render` pipeline on the Command Window (`Tab`), including sticky hysteresis water-droplet sub-clustering (`clusterDivisionMembersSticky`), 2D Smooth-Union SDF + Marching Squares contour extraction, and interactive right-side **Time**, **Space**, **Firepower**, and **Convergence** Warroom layer buttons.
- **`DivisionEditorDialog.java`**
  - `1320x800` modal UI for **Fleet Organization** (Screen 1: interactive division cards, drag-and-drop `ShipIconTile`s with lower-left commander portraits and lower-right division leader stars, Unassigned Ships pool) and **Configure Division** (Screen 2: 2x8 archetype selector grid, 10 geometric `DivisionFormation` emblems, and per-division spacing/standoff/mission overrides).
- **`FleetDoctrineDialog.java`**
  - `1320x800` modal UI for **Fleet Doctrine** (Command Scheme and Preferred Tactics with `168x168` clickable Naval Pennants, Fleet-Wide Formation & Setpiece selectors, Division Modifiers, Auto-Assigner Division Schemes, Hull Limits, and Nomenclature customization).
- **`DivisionFleetTabInjector.java`**
  - Injects the `"Fleet Doctrine"` (`icon_gold-star`) and `"Fleet Organization"` (`icon_gold-wing`) buttons onto the left sidebar of the campaign Fleet tab (`CoreUITabId.FLEET`).
- **`CampaignFleetTooltipOrganizer.java`**
  - Sorts the campaign fleet mouseover tooltip (`StandardTooltipV2`) into division rows with vertically expanded multi-row division header cards.
- **`DivisionDeploymentDialogOrganizer.java`**
  - Enlarges the pre-battle Deployment Window from `10x3` (`614x174`) to `16x7` (`960x406`, 14 ships + 2 header columns per row), sorts reserve ships by Permanent Divisions with `*LDR` division leader badges and 1-click `Select (X DP)` buttons, and adds the top **Fleet Command** panel (`940x204`) with clickable `122x122` Command Style Naval Pennant and pre-battle `108x108` Formation Wheel.
- **`DivisionAISettings.java`**
  - Reads `mod/data/config/LunaSettings.csv` (`ChatterVerbosity`: `Verbose`, `Standard`, `Minimal`, `OTC Only`, `Off`; per-side OTC/Division/Multi-Division toggles; Tactical Map overlay opacity; and the two-click `"Reinitialize Sector-Wide Division Lists"` button).

## Critical Invariants (Enforced by `./test.sh`)
1. **Zero `java.lang.reflect` References**: Starsector's script classloader blocks `java.lang.reflect.*`. Always use `java.lang.invoke.MethodHandles` when bridging obfuscated UI classes. Scenario 8 of `./test.sh` scans every `.class` constant pool in `DivisionAI.jar` for `java/lang/reflect`.
2. **No `%` Characters in `LunaSettings.csv`**: LunaLib passes `fieldDescription` into `TooltipMakerAPI.addPara`, which invokes `String.format()`. Any raw `%` throws `MissingFormatArgumentException`.
3. **Never Forcibly Assign Player Ships to Divisions**: Player ships are only assigned to divisions when the player explicitly clicks Auto-Assign (and confirms `"Are you sure?"`) or assigns ships manually in Fleet Organization.
4. **Strict Fog of War & Command Window Order Respect**: Never target or route toward unspotted enemy divisions in `FogOfWarAPI`, and never override explicit non-`SEARCH_AND_DESTROY` player orders in `CombatTaskManagerAPI`.
